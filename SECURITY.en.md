# Reporting security issues

Report vulnerabilities privately through GitHub Security Advisory, not public issues.

1. Open this repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Describe how to reproduce it and the impact, then submit.

Do not paste secrets, tokens, or HMAC keys into public issues or reports. If a live key value was exposed, do not repeat it; just state that it was revoked.
